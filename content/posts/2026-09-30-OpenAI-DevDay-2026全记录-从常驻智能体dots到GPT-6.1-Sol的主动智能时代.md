2026年9月29日，OpenAI 举办了迄今为止规模最大的一届 DevDay，一口气放出超过 20 项更新，横跨 ChatGPT、Codex、模型体系以及人与 AI 协作的全新方式。与往年"模型参数竞赛"的主线不同，今年 OpenAI 把叙事重心从「更聪明的模型」转向「更主动的智能」：让 AI 不再只是等你提问，而是持续地承担职责、在云端替你干活。这届 DevDay 的本质宣言清晰而直接——**ChatGPT 正在从"一个对话产品"变成"人与智能体协作的共享平台"**，OpenAI 希望开发者直接面向其自称的 12 亿周活跃用户构建原生体验。

本文基于 OpenAI 官方 DevDay 2026 回顾、官方产品公告，以及界面新闻、新浪财经/中华网、Tech Bytes 等对技术细节与定价的报道，梳理这届大会"讲了什么、发了什么、怎么理解"。

## 一、一句话概括这届 DevDay

OpenAI 在 9 月 29 日释放的更新可以浓缩为四条主线：

1. **主动智能（Proactive Intelligence）**：推出常驻智能体 **dots**，全天候在云端帮你干活；
2. **性价比模型**：推出 **GPT-6.1 Sol**，以 Astra 五分之一的 Token 价格提供接近 Astra 的能力，主打智能体编程与专业工作；
3. **Codex 全面上云**：Codex Cloud、语音版 CLI、代码审查、Codex Security Cloud，把编程 Agent 变成可随时调度的云服务；
4. **平台化开放**：插件扩展开放 ChatGPT 构建应用、OpenAI Marketplace、Sign in with ChatGPT 全球化。

CEO 山姆·奥特曼在演讲中给出了理想主义的注解：如果方向正确，AI 带来的未来更像是一场"新的文艺复兴"，它应当让人们更能掌控自己的生活，获得更多创造、学习和发现的工具。

## 二、核心新品一：常驻智能体 dots——"持续在职"的 AI 同事

### 2.1 它是什么

dots 是本场发布的重头戏，官方定位为"能力出众、全天候运行的智能体，能够持续承担职责"。它由 OpenAI 目前"最智能、最符合对齐目标的模型 GPT-6 Astra"驱动，拥有**独立的云端计算机和浏览器**，可通过插件生态连接超过 4000 个应用，并在 ChatGPT、Slack、Microsoft Teams 等渠道与你交流进度。

关键特性在于"持续"二字：与一次性问答不同，dots 在被赋予一个目标和明确的权限边界后，会**主动地、跨会话地**为你推进工作，即使你关掉应用，它也在云端继续运转。

### 2.2 它能做什么：奥特曼的案例

奥特曼特意指出，订餐厅、买机票这类任务"虽然有用，但相对技术潜力仍然很小"。他希望用户把**更复杂、更需要主动判断的任务**交给 AI。他举的例子包括：

- 在旧 API 停用之前，让 dot 查清相关代码依赖、判断修改范围、编写代码并运行测试，再把代码修改提交团队审查；
- 持续监控软件故障报告；
- 跟进年度预算规划；
- 查找并修复应用运行缓慢的问题。

个人使用场景上，奥特曼表示 dots 可以在夜间查看收到的信息、早晨提醒紧急事项，帮他减少对手机的依赖，把注意力放在自己重视的事上。

### 2.3 权限与安全设计

在安全备受关注的大背景下，dots 的权限被刻意收紧：

- 用户可设置 dot 能够访问的应用及操作规则；
- 在用户未主动交互时，后台的"**主动研究（proactive research）**"**仅使用只读工具**，不能发送消息或修改应用内容；
- 可能影响账户或分享信息的操作，需经过**自动审查**，判断是否符合授权或需进一步审批；
- 与专业经济体协作时另有专门通道。

### 2.4 资费与可用性

- 面向 **Pro 和 Business Premium** 用户开放（符合资质的市场），首个 dot 免费包含在订阅内；
- **Enterprise、Edu、Healthcare** 工作空间提供需管理员开启的测试版；
- 组织版还可以配置**专属 dots（specialist dots）**，带独立凭据，并可集成进 **Microsoft Agent 365**；
- 与 dot 的对话不计入 ChatGPT 用量上限，但 dot 触发的 Codex 和 ChatGPT Work 任务仍会计入。

多个 dot 可由用户组成"团队"协同工作——这是官方明确描绘的下一步演进方向。

## 三、核心新品二：GPT-6.1 Sol——"接近旗舰、价格打五分之一"的高性价比主力

### 3.1 定位

GPT-6.1 Sol 是 GPT-6 Sol 的一次重大升级，在**智能体编程、计算机使用、专业工作**三类任务上表现尤为出色。官方称它让 Sol 在高难度任务上的表现**更接近 GPT-6 Astra**，而输入和输出 Token 价格仅为 Astra 标准价格的**五分之一**（Tech Bytes 更精确地给出"四分之一"说法，公私信源略有差异，均指向其性价比优势）。

### 3.2 定价明细（Tech Bytes 数据）

- API ID：`gpt-6.1-sol`
- 输入：每百万 Token **2 美元**；缓存输入仅 **0.10 美元**
- 输出：每百万 Token **10 美元**
- 在 **DeepSWE v1.1** 评测上，GPT-6.1 Sol 达到与 Astra 高端档相当的准确率，同时任务执行成本**下降约 80%**
- 缓存输入的低价会对 Agent 经济性产生实质性影响（长 Agent 循环中大量 token 来自缓存）

### 3.3 可用性

- 已面向所有 API、Plus、Pro、Business、Enterprise、Edu 用户开放；
- 在 **ChatGPT Work 和 Codex** 中即刻可用（付费计划），但**暂未进入常规 Chat**；
- GPT-6.1 Sol 的 **Ultrafast** 档位"即将推出"。

## 四、"速度即体验"：Ultrafast 超高速档位

OpenAI 推出面向延迟敏感负载的**超高速档位（Ultrafast）**：

- 在 **Codex** 中可将 Token 生成速度提升至**最高 8 倍**（每秒约 **300 token**）；
- 在 **API** 中最大约 **6 倍**吞吐；
- 价格约为标准档的 **6 倍**：每百万输入 **60 美元**、每百万输出 **300 美元**；
- **GPT-6 Astra Ultrafast** 现已在 API 推出，并面向 Pro 500 与 Enterprise 用户开放于 ChatGPT Work 和 Codex。

它锚定了新增的每月 500 美元 Pro 套餐（见下文）。

## 五、订阅体系调整：Pro 500 套餐与隐性的"档位收缩"

### 5.1 新增 Pro 500 套餐

为满足更高构建需求，OpenAI 推出**每月 500 美元的 Pro 套餐**：

- 提供约 **25 倍于 Plus 的用量额度**；
- 专享 **Astra Ultrafast**——速度最快的前沿模型；
- 在 ChatGPT Work 和 Codex 中速度最高可达标准 Astra 的 8 倍。

### 5.2 旧 Pro 套餐"缩水"（值得留意）

据 Tech Bytes 披露，200 美元的 Pro 套餐对新订阅用户做了调整：

- ChatGPT Work 和 Codex 用量从 "20 倍 Plus" 降至 "**10 倍 Plus**"；
- 每周 GPT-6 Pro 消息数从 200 条降至 100 条。

这种"抬高天花板、压缩中档"的组合，被解读为将重度用户向 Pro 500 引导的策略。

## 六、Codex 全面云化：从终端工具到可调度的开发平台

Codex 迎来了发布以来最大的一次更新，核心是**让它长在云上、被团队共享、并具备安全闭环**。

### 6.1 Codex Cloud

- 按需运行：在电脑上、通过手机远程、或任意设备从云端运行；
- **可复用的开发环境**，任务快速启动；
- 为团队提供**采用已批准设置和权限的共享配置**；
- 适用于 Plus、Pro、Business、Healthcare、Education、Enterprise 所有套餐。

### 6.2 焕新升级的 Codex CLI

- 支持**语音对话**：直接与 Codex 对话来启动并引导任务；
- 新增 **/agents 视图**：把工作分配给多个智能体，跟踪多项任务进度；
- 改进日常流程：编辑提示词、恢复会话、内置工作树支持；
- 更新终端界面，更简洁、长会话更易读。

### 6.3 代码审查

- ChatGPT 桌面应用中全新的**代码审查体验**，快速把握各项目需关注的重点；
- 反馈前可浏览摘要、深入查看 diff、向 Codex 提问潜在问题；
- 支持**自动审查**：Codex 在你不在时于云端完成初审；
- 支持 GitHub Pull Request 和 GitLab 合并请求。

### 6.4 Codex Security Cloud

- 将 **Defense Factory** 的持续防御方法引入 Codex，并提供对 **Daybreak Blue** 模型的访问（无需另行申请）；
- 团队可**持续检查新提交**，也可按需或定时扫描整个 GitHub 仓库；
- 调查、去重、修复均在云端运行——合上笔记本仍在继续；
- 以插件形式提供，面向所有 Codex 用户。

### 6.5 Agents API 的计算机使用能力

- Agents API 现已支持开发者以**托管方式**使用 Codex 执行框架；
- 支持多智能体、工具搜索、工具调用、压缩，以及新增的**计算机使用（computer use）**；
- 可通过 API 使用，500 美元 Pro 用户及符合条件的 Enterprise 客户也可在 Codex 与 ChatGPT Work 中使用。

### 6.6 面向 OpenAI 的 Amazon Bedrock 托管智能体

- 基于核心 Agents API，加入 AWS 定制与集成，使用**客户控制的计算和 AWS 资源**；
- 让基于 AWS 的团队将托管智能体系统与现有基础设施配合。

## 七、Decisions API：用 Luna 做"受限决策"

- 将 **Luna** 的智能集中于一组用户定义的问题，每个问题带**有限的预定义答案**，实现实时决策；
- 开发者通过文本或图像提供上下文，答案可用于内容分类、路由请求或选择智能体下一步操作；
- 返回受约束分类的延迟约 **150 毫秒**；
- 今日起限量预览，计划数天内广泛发布。

## 八、平台化：把 ChatGPT 变成应用平台

这可能是战略意义上最重的一步——OpenAI 将 ChatGPT 本身开放为开发目标。

### 8.1 插件扩展（Plugin Extensions）

- 开放构建 ChatGPT 功能的平台，开发者可直接在 ChatGPT 内构建**应用内体验**；
- 可为插件在**侧边栏设置专属入口**；
- 构建可供用户边对话边工作的**交互面板**；
- 为产品支持的文件类型创建**查看器**。

### 8.2 更完善的插件创建 / 提交 / 发现

- 插件创建工具 + 重新设计的提交流程；
- 改进插件目录与对话中的排序、推荐；
- 用户始终自选插件，并逐一批准访问权限。

### 8.3 MCP 事件驱动自动化

- 加入对**拟议的 MCP 事件规范（triggers/events）**的支持；
- 插件能在已连接应用发生事件时**启动自动化**；
- 例如：让 ChatGPT 关注项目看板上的新任务，有新任务时即使你不在，它也能阅读文档并起草计划。

### 8.4 OpenAI Marketplace（企业）

- 让企业把已有的 OpenAI 支出承诺，定向用于约 **32 家首发合作伙伴**的产品，含 Adobe、Figma、Salesforce、ServiceNow、Palo Alto Networks、CrowdStrike 等。

### 8.5 Sign in with ChatGPT（使用 ChatGPT 登录）

- 用 ChatGPT 账号登录合作产品，无需再设密码；
- 合作伙伴仅收到姓名、邮箱、头像；
- **不共享聊天记录或记忆**；其他访问权限需另行批准；
- 全球化开放，Plus/Pro 用户可在约 16 个合作伙伴工具（含 Cognition 的 Devin、Notion、Vercel、T3、OpenClaw、Dactyl 等）中直接使用订阅额度（带应用级限制）。

## 九、人机协作新工作流：ChatGPT 变成"团队空间"

### 9.1 ChatGPT 资料空间（ChatGPT Space）

- 与 AI 和团队一起工作的全新空间：把成员加入专属空间，所有人（含 ChatGPT）结合共同目标和历史工作继续推进；
- ChatGPT 可将对话转为页面或幻灯片，先提问明确需求再起草；
- Pro、Business、Enterprise 用户可在桌面端和网页版使用，移动端即将推出。

### 9.2 动态页面（Dynamic Pages）

- 面向"与智能体和团队共同完成工作"的新文档类型；
- 与 ChatGPT 或 dot 协作生成图表、交互式仪表板、图像；
- 设置页面可从已连接工具自动更新（如待办清单、团队跟踪表）。

### 9.3 协作式幻灯片

- 全新演示文稿编辑器：原生可编辑图表、文本、形状、图像；
- 将对话转成幻灯片，或从模板开始，过程中向 ChatGPT 反馈；
- 多位成员可同时编辑、评论；
- 可导出到 PowerPoint 或 Google Slides 并保留格式。

### 9.4 创建团队、共享任务

- 将同事加入团队，共享页面、演示文稿、电子表格等；
- 创建**团队任务**，把每周项目进展汇报等重复工作交给 ChatGPT；
- 可定时运行，或在变化发生时触发（如收到新邮件/Slack 消息）；
- 团队成员共同更新指令。

### 9.5 Slack 与 Microsoft Teams 中的 @ChatGPT

- 在频道、消息串或私信中提及 @ChatGPT，可将讨论转为项目简报、排查 bug、准备修复方案、发布客户动态；
- 即使没有个人 ChatGPT 许可，团队成员也能在同一对话中补充上下文；
- 面向 Business、Enterprise。

### 9.6 会议插件

- 录制会议音频，将纪要保存在 ChatGPT 资料空间；
- 可私密或共享；ChatGPT 结合历史上下文总结要点、决策和行动项；
- Pro、Business 已开放测试版，Enterprise 即将开放。

### 9.7 可分享的个人资料页

- 展示自己的站点和插件，供他人发现和复用；
- 团队成员可发现共享技能（仅限工作空间内）。

## 十、面向企业的"隐私智能"

- **带隐私安全处理的零数据保留（Zero Data Retention with Private Safety Processing）**：支持离线自动安全审查，且 OpenAI 不保留客户内容；
- **隐私推理（Private Inference）预览版**：将机密计算与严格、可验证的控制措施结合，为客户提供强隐私保障；正式预览将在今年秋季推出。

对企业客户，这解决了"用前沿模型但数据不可外泄"的核心矛盾——安全审查也在本地/私有执行，而非上传云端。

## 十一、怎么理解这届 DevDay：三个信号

### 11.1 从"对话"到"平台"，ChatGPT 的战略位置变了

DevDay 不再以"跑分更高的模型"为唯一主角，而是把 ChatGPT 重塑为**人与智能体协作的共享平台**。无论是插件扩展、Marketplace，还是 Sign in with ChatGPT、12 亿周活用户，都在指向一个结论：OpenAI 想让开发者**建立在 ChatGPT 之上**，而不是在它旁边。这与其说是"AI 应用商店"，不如说是 OpenAI 对"智能体操作系统"生态位的争夺。

### 11.2 "主动智能"是 next step，但安全护栏同步收紧

dots 的"主动研究只读、高风险操作自动审查、权限可配置"设计，是对"AI 自主行动"给公众信任造成冲击的主动回应。OpenAI 显然明白：真正让 Agent 走进工作流的瓶颈不在能力，而在于**可被信任的权限边界**。如何让 AI 强、又让人始终掌控，是这届 DevDay 未明说但贯穿始终的技术命题。

### 11.3 价格杠杆：用 Sol 铺量，用 Ultrafast/Pro 500 收高价值

GPT-6.1 Sol 的"低单价"与缓存输入 0.10 美元/百万的设计，是在为**长程 Agent 经济性**服务——Agent 循环里绝大多数 token 是重复上下文，缓存价格直接决定智能体的运行成本。而 Ultrafast 与 Pro 500 则把"低延迟、高吞吐"作为差异化卖点回收溢价。性价比与速度两头定价，中间档位收缩，本质是对核心用户群（开发者与重度 Agent 用户）的精准分层。

## 十二、给开发者与观察者的行动清单

- **先验证 dots 在你所在市场和套餐档位是否可用**，再围绕它构建工作流；
- **用 `gpt-6.1-sol` 对现有模型做基准**：其 0.10 美元/百万的缓存输入价格会显著改变 Agent 的单位经济性；
- **读插件扩展文档**，趁目录还没拥挤时把位；
- 关注即将到来的 **GPT-6.1 Sol Ultrafast**、今秋的 **Private Inference 预览**，以及旧 Pro 套餐缩水是否会把重度用户推向 Pro 500。
